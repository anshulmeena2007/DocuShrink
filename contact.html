Tips for Reporting a Technical Issue

Because DocuShrink executes entirely within your web browser, issues are typically related to device memory limits, browser version compatibility, or unusual file structures. When reporting a problem, including the following details helps us reproduce and resolve it quickly:

1. Web Browser:
Chrome, Safari, Firefox, Edge, etc. and version
2. Device & OS:
Windows, macOS, iOS, Android, or Linux
3. File Details:
Approximate file size, image format (JPG/PNG/WebP), or PDF page count
